How fields and mapping work
Existing DSENY mode retains the original table positions. Use placeholders for redesigned layouts: type fields such as {{project}} or {{inspection_date}} in Word. Fonts, colors and layout remain in your DOCX. Names like {{school_name}} can be mapped to Project below. Attendees and open items become formatted text lists in their placeholder. Separate per-item table-row loops are not supported.
Required fields for custom templates: {{client}}, {{project}}, {{product}}, {{inspection_date}}, {{status}}, {{attendees}}, {{locations}}, {{open_items}}.
